# 共享访问凭据与后端鉴权

本项目不提供登录页、开发者账号或钉钉免登。用户从知识沉淀统一入口进入，注册中心读取同域共享凭据，直接调用后端业务接口。页面路径见[页面路由](routing.md)，代理配置见[环境与部署](deployment.md)。

## 上游交接约定

统一入口负责登录、保存及更新凭据，双方使用以下约定：

| 项目 | 约定 |
| --- | --- |
| 存储类型 | 同源 `localStorage` |
| 键名 | `access_token` |
| 值格式 | 原始 token 字符串，不添加 `Bearer `，不使用 JSON 包装 |
| 请求头 | `Authorization: Bearer <access_token>` |

上游保存 token 后导航至注册中心目标页面。注册中心每次请求读取最新值，不复制到自己的会话、不写入或清除共享键，也不使用 URL、旧开发配置或旧 `sessionStorage` 作为备用凭据。刷新页面继续读取共享值，不自行推测 token 有效期。上游和注册中心必须协议、域名、端口一致；不同路径共享存储，不同端口或协议不共享。本机不同 Vite 端口直连不构成同源，应通过同一域名网关联调。

前端不再需要 `REGISTRY_AUTH_MODE`、`REGISTRY_DEVELOPER_ACCESS_TOKEN`、`REGISTRY_DINGTALK_CORP_ID`，构建不注入登录配置，已移除钉钉 SDK。上游及后端需自行保证此 token 能被业务接口接受；注册中心不签发、交换、续期或撤销 token。

## 进入与账户资料

入口直接加载业务页面，不调用登录接口或进行身份预检。首屏业务数据、图标与渲染准备期间展示五色竖条动画，同时绘制分子背景；就绪后加载层淡出，工作台淡入。业务失败保留错误与重试，认证或权限失败使用下述回退页。

账户栏并行调用 `GET /knowledge-accumulation/registry/api/auth/me`，成功响应仅包含非空字符串 `userid` 和 `username`，前者为中央用户标识，后者为中央登录查询返回的用户名；不再读取 `name`、部门、头像或权限字段。右上角显示 `username`，无效响应或资料尚未取得时隐藏名称，不回退到旧姓名。此接口并行读取，不作为业务加载的前置条件，也不保存会话；后端确认中央会话并滑动续期，再校验注册中心管理员资格。401 表示登录无效，403 表示不是注册中心管理员，均使用现有回退机制；503 等资料读取失败不阻塞其他业务错误展示。右上角原退出按钮改为“返回知识沉淀”，不会登出统一入口或清除共享凭据。

本人审核历史直接采用后端按 Bearer 身份返回的记录，不依赖已缓存的用户资料过滤，避免资料未就绪时误显示空列表。

## 缺少凭据、失效与无权限

| 情况 | 页面行为 |
| --- | --- |
| 初次进入缺少、格式非法或无法读取共享 token | 显示“请从知识沉淀入口进入”，不请求业务接口 |
| 业务或身份接口返回 401 | 隐藏工作台，显示“登录状态已失效”及返回按钮 |
| 接口返回 403 | 隐藏工作台，显示“暂无注册中心访问权限”及返回按钮 |
| 网络失败、超时、5xx | 保留对应业务错误和重试，不判定为无权限 |

回退按钮采用 Uiverse.io / ke1221 的浅灰浮雕样式，按下呈内凹效果。使用普通链接完整导航，开发返回 `/dev/knowledge-accumulation/`，构建部署返回 `/knowledge-accumulation/`，不依赖浏览器历史。401/403 不清除统一入口的共享 token，也不自动发起登录；旧 token 请求迟到返回错误时，不阻断已更换的共享凭据。

## 请求边界与验证

[`registryApi.js`](../../src/services/registryApi.js) 约束请求只在注册中心同源 API 范围内，外部 URL 不附加凭据。JSON 和文件原件默认使用 `no-store`，15 秒期限覆盖响应体读取，支持取消。人员权限与文件等级更新使用 60 秒期限，组织架构刷新使用 330 秒；头像单独使用浏览器私有 HTTP 缓存，详见[人员管理](../features/personnel.md#头像读取与释放)。原件展示及页面内 Blob 缓存见[文件展示器](../features/file-preview.md)。

此前隔离测试覆盖共享 token 读取及更新、缺少凭据、401/403 回退事件、迟到响应、请求范围、超时、原件和业务流程。使用隔离凭据及数据验证浏览器进入、刷新、账户展示及回退，不操作真实审核记录。测试目录按项目要求被 Git 忽略；当前可运行范围与验证限制见根目录 [README](../../README.md#构建预览与验证)。
