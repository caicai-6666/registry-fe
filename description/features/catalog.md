# 正式文件目录与原件接入

数据中心结果列表使用 `GET /knowledge-accumulation/registry/api/catalog/list`，点击表项后使用 `GET /knowledge-accumulation/registry/api/resource/file/{resource_id}` 获取原件。两者均携带共享用户 `access_token` 的 Bearer 凭据，构建部署请求经 `/knowledge-accumulation/registry/api/` 同源代理，开发浏览器请求增加 `/dev` 前缀，由网关与 Vite 原样转发。契约见[后端目录 API](../../../registry-be/description/api/catalog.md)与[后端原件 API](../../../registry-be/description/api/resource.md)。

## 目录与展示模型

[`catalogApi.js`](../../src/services/catalogApi.js) 读取真实目录；[`catalogFile.js`](../../src/models/catalogFile.js) 校验并映射目录公开字段，不采用响应中额外的 URL 或内部路径。

| 后端字段 | 页面用途 |
| --- | --- |
| `id` | 正式资源身份与原件路径，精确保存为十进制字符串 |
| `name` | 文件名称；历史 null 显示“未命名文件 #ID” |
| `source_platform` | 来源平台代号；可查询到平台时显示名称，否则保留代号 |
| `applicant` / `reviewer` | 右侧纵向对齐的人员信息，null 或空白显示“—” |
| `ingested_at` | 入库时间，按浏览器本地时区显示至分钟 |
| `abstract` | 摘要悬浮层，无摘要显示“暂无摘要” |
| `file_level` | 文件等级，映射为 `fileLevel`，保留精确整数；null 或历史缺失保持未知，用于[文件等级悬浮层](file-preview.md#文件等级悬浮层)，不额外请求或在列表添加标签 |
| `passport` | 最终通行证数组，不在表项展示；打开文件后在预览区的通行证悬浮层逐项展示，长值换行；null 或旧接口缺失显示“—”，空数组显示“无通行证” |

目录不包含媒体类型，文件响应的 `Content-Type` 决定展示类型；通用二进制类型回退到目录文件名，历史未知名称时再使用 `Content-Disposition` 中的保存文件名。当前支持 PDF、音频和视频渲染，未知类型显示不支持内嵌预览提示及文件打开链接。

目录 ID 支持 MySQL unsigned BIGINT 上限，使用 JSON.parse 的原始数字文本上下文读取，避免精度损失；无法精确恢复大 ID 的浏览器会拒绝该响应，不用舍入后的 ID 请求原件。重复或越界 ID、无时区时间及字段类型错误不会形成部分结果。

列表在筛选后按完整入库时间降序排列，并按浏览器本地入库年月分组，显示“2026 年 10 月”及细分隔线，风格参考 `contract-service-fe` 合同库。同一月份内最新文件在前，相同时间保留原顺序，跨年月份分别展示；排序逻辑位于 [`catalogTimeline.js`](../../src/models/catalogTimeline.js)，不修改原目录数组。月份标题与文件使用同一过渡组，筛选至无文件的月份会随之移除，不留下空分组。

## 加载、筛选与异常

[`DataCenterPanel.vue`](../../src/components/DataCenterPanel.vue) 持有目录与筛选状态，调用 [`useCatalog()`](../../src/composables/useCatalog.js) 在首次进入数据中心时读取目录，成功后（包括空数组）在当前页面缓存；切换回来及恢复页面可见时复用数据，不重复请求或显示 loading。手动刷新和错误重试主动获取最新目录；首次失败或中断不视为完成，可重新进入重试。离开／隐藏取消未完成请求，卸载清理监听；页面刷新、组件卸载或共享访问凭据改变后重新加载。目录不固定轮询，与平台同步计划独立。并发触发合并为当前请求，取消后的晚到响应不覆盖结果。失败显示后端错误和重试按钮，并保留上次成功目录；成功空数组或筛选无匹配时显示 `empty.webp` 和“空空如也”；读取及刷新使用居中转圈，遵循[列表与详情的状态展示](workspace.md#列表与详情的状态展示)。

后端当前一次返回全部文件，不分页、不接受过滤参数。前端未选平台时展示全部记录；选中平台后按 `source_platform` 在本地过滤，支持多选和全选。平台、时间、通行证前缀及文件名、摘要、申请人、审核人条件均在前端过滤并取交集。不因来源平台当前不存活而删除正式文件记录。

## 文件筛选

右侧文件列表区域的右上角提供“刷新文件列表”按钮，复用审核记录的圆形刷新样式及整圈旋转动画，点击重新读取正式目录。刷新保留筛选条件和上次成功数据，失败沿用列表错误及重试提示；加载期间禁止重复点击。按钮位于独立工具区，列表滚动时保持可见；窄屏仍位于列表上方右侧。

[`CatalogFilters.vue`](../../src/components/CatalogFilters.vue) 参照合同库筛选条，用 [`CatalogDateFilter.vue`](../../src/components/CatalogDateFilter.vue) 的年／月／日滚轮筛选入库时间。条件筛选在左侧栏分为日期、文件信息、通行证及人员三个层次，以细分隔线和留白区分，不增加卡片容器或标题；入库时间标签位于滚轮左侧；文本输入采用波浪浮动标签，具体交互见下文，日期滚轮保留浅色平面样式。平台同步和平台选择也位于左栏，文件列表位于右侧。窄屏整页上下排列，不增加独立框容器。

平台概览顶部的“全选”旁提供“重置”按钮，采用用户提供的 Uiverse.io / elijahgummer 浅灰立体按键样式，保留多层阴影与按下下沉效果，适配为带图标的紧凑按钮，一次清空平台选择、入库年／月／日、通行证前缀及四项关键词，并关闭通行证提示。重置仅恢复本地筛选，不重新请求目录或改变平台同步计划；未选择平台表示不限平台。

- 文件名、文件摘要、申请人和审核人按文本模糊匹配，忽略首尾空白及英文大小写：空格分隔的关键词均需命中，每个关键词内部允许按原文顺序跳字；空关键词不限，缺失字段不匹配非空关键词。文件名、申请人、审核人提供完整目录中的候选提示，去重并排除空值及“—”，按相同文本规则过滤，完整相同、前缀、包含、跳字匹配依次优先，最多 20 条。文本及通行证输入过程中仅更新草稿和候选提示，离开输入控件后才应用筛选；点击候选或清空按钮直接确认该值，重置同时清空草稿及已应用条件。平台和日期选择仍即时应用。所有输入提示（含通行证）仅在输入非空白内容后展示，清空或重置立即隐藏，单独聚焦空输入不展示。摘要不提供候选提示，所有条件在本地组合，不增加接口参数。
- 年份来自全部目录中的入库时间，默认“—”表示不限；选年后可选月，选月后可选日。滚动、点击及方向键均可操作，Home／End 到达两端。
- 清空年同时清空月、日，清空月同时清空日；更换月份或年份时自动将超出月底的日期调整到当月末，包含闰年规则。目录更新后选中年份已不存在时重置日期。
- 过滤与列表显示使用同一浏览器本地时区。仅选年筛选全年，选到月筛选整月，选到日筛选当天。
- 日期、通行证前缀、四项关键词与平台选择在工作台路由切换时保留，整页刷新或退出后恢复默认，右侧刷新目录按钮保留条件；无匹配结果显示 `empty.webp` 和“空空如也”。

结果列表通过过渡组呈现：新增表项淡入并从右滑入，移除表项向左滑出并淡出，保留表项平滑补位；空结果提示延后淡入，减少动画偏好下关闭过渡。

过滤逻辑集中在 [`catalogFilters.js`](../../src/models/catalogFilters.js)，列表组件只接收已筛选文件及加载状态。

## 鉴权原件与缓存

`registryApiFileRequest()` 复用 JSON 请求的同源路径约束、15 秒请求／响应体期限、取消、错误 detail 和 401 会话失效机制。成功读取完整 Blob 和响应头；错误 JSON 不交给文件渲染器，网关返回的 HTML／JSON 页面也不作为原件缓存。不会把 token 放入 URL。

展示器按资源 URL 缓存下载 Blob，再创建本地 blob URL 供渲染器、新窗口和下载使用。关闭弹窗撤销该次 blob URL，保留 Blob；再次打开同一文件不会重复调用原件接口。PDF 每次创建独立字节副本交给 Worker。缓存随展示器卸载、退出和刷新清空，失败可重试；完整机制见[文件展示器](file-preview.md#页面内临时文件缓存)。

目录刷新或筛选变化发现正在预览的文件不在当前结果中时关闭预览。文件内容同 URL 更新时仍需主动失效缓存或提供版本化资源地址，当前接口未提供版本字段。

页面仅展示后端正式目录，临时多通行证示例及其注入逻辑已移除。通行证筛选、提示及文件预览浮层均使用后端返回的数组。本地 PDF 示例资产保持移除；隔离联调使用后端测试目录的 PDF fixture，不写入生产数据。

## 通行证前缀匹配

通行证属于左侧条件筛选，按去除输入两端空白后的前缀匹配，区分大小写。输入时仅更新候选，失焦后应用；点击候选或清空直接确认。空条件不限通行证，非空条件不匹配 null 或空数组；任一通行证命中即可入选。

候选从完整目录的通行证数组展开、去重排序，最多显示 20 项；仅输入非空白内容后展示。支持点击或用 Tab 聚焦后回车选择，Escape 收起提示。通行证原值、数组顺序和重复值不因提示去重而改变。

## 通行证数组契约

[`passport.js`](../../src/models/passport.js) 是前端统一数组解析入口，适用于正式目录、入库审核决定及历史、删除待审列表及历史。每项必须是非空白字符串，最多 512 个 Unicode 字符；保留原值、顺序与重复项，不裁剪、不按逗号或 JSON 文本拆分。读取时 `null` 与 `[]` 保持区别，旧 HTTP 单字符串不再接受。具体规则见[后端通行证数组契约](../../../registry-be/description/architecture/data/passport.md)。推荐列表中的 `{passport, reason}` 仍使用单个字符串，未改为数组。

[`PassportValues.vue`](../../src/components/PassportValues.vue) 在正式文件预览悬浮层和两种审核历史中逐项展示数组，保留重复值，`[]` 显示“无通行证”，null 显示“—”。只有搜索候选去重，不改写记录本身。
