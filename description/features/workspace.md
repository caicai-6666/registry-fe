# 注册中心导航与数据中心

本页说明注册中心的三个导航页面与数据中心布局。数据中心采用左右布局，左侧为平台及条件筛选，右侧为文件列表，已移除左侧对话区域、手写欢迎动画及可调节分隔条。页面入口见[页面路由](../platform/routing.md)。

## 导航页面

顶部通过路由切换“数据中心”“审核广场”“人员管理”，默认进入数据中心。选中滑块与页面采用 520ms 横向过渡，页面按导航索引决定进入及退出方向，浏览器前进／后退使用相同规则。减少动画偏好下直接切换。

三个页面通过单个 RouterView 和 KeepAlive 缓存实例；首次访问创建页面，停用后移出活动 DOM，返回复用原实例并恢复各滚动容器位置、筛选及审核表单状态。过渡期间离开页使用 inert 与 aria-hidden 禁止交互并从辅助技术中隐藏。具体生命周期见[页面缓存与生命周期](../platform/routing.md#页面缓存与生命周期)。数据中心展示正式目录，审核广场提供[入库与删除审核](review-square.md)，人员管理提供[定位与筛选](personnel.md)，使用正式用户、部门与头像接口；平台状态在数据中心、审核广场、人员管理可见或审核记录弹窗打开时同步。

## 数据中心布局

[`WorkspaceView.vue`](../../src/views/WorkspaceView.vue) 负责工作台容器、共享平台目录及平台选择，不再维护对话状态、左右尺寸、拖拽事件或尺寸观察器。桌面展示左筛选、右文件两栏；900px 及以下按筛选区、文件列表上下排列，较矮窗口可滚动，不再预留对话区高度。

[`DataCenterPanel.vue`](../../src/components/DataCenterPanel.vue) 将左侧固定为约 380–460px 的筛选栏，包含平台同步、平台选择、入库日期、通行证前缀及文件与人员关键词；右侧占据剩余宽度，右上角提供文件列表刷新按钮，列表独立滚动。两栏使用连续透明表面和渐隐分隔线，不新增厚重框容器。平台文件夹在左侧按可用宽度换行，较多时纵向滚动，保留边缘羽化；条件筛选按日期、文件信息、通行证及人员分层纵向排列，以细线与留白区分，标签位于控件左侧并统一对齐；文本输入与日期滚轮采用浅色平面样式，底部保留紧凑重置按钮，刷新按钮位于右侧列表上方，滚动列表时保持可见。文件表项保留浅绿卡片、圆角及悬停反馈，按入库时间降序和入库年月分组；月份标题、文件退出入场和补位沿用统一过渡。

| 区域 | 用途 |
| --- | --- |
| 左侧：平台概览 | 独立平台文件夹、名称及在线状态，支持点击筛选和全选；按后端同步计划更新 |
| 左侧：条件筛选 | 入库日期、通行证前缀、文件名、摘要、申请人、审核人及重置 |
| 右侧：文件列表 | 文件名、来源平台、入库时间，右侧纵向对齐申请人与审核人；点击查看原件 |

平台模型与调度见[平台查询](platforms.md)，筛选交集、目录、鉴权及错误处理见[正式文件目录](catalog.md)。页面仅展示后端真实数据，不保留本地示例。

## 文件预览

点击表项或键盘激活后，由 `RegistryFilePreview.vue` 接入通用展示器，按文件类型分发 PDF、音频或视频。文件内容显示完成后淡入摘要及通行证悬浮入口；通行证不在表项中展示。预览支持临时缓存，展示器、PDF 阅读器及扩展方式见[文件展示器](file-preview.md)。

## 验证

功能测试覆盖平台选择、目录筛选、本地月份边界与稳定排序；当前总体测试基线见根目录 [README](../../README.md#构建预览与验证)。本次通过独立无头 Chrome 检查 1440 × 1000 桌面布局、输入提示、失焦筛选、重置及月份分组；窄屏与完整动画时序未在本轮重新复核。

## 列表与详情的状态展示

[`ContentState.vue`](../../src/components/ContentState.vue) 统一以下 12 个内容容器的状态：

| 区域 | 列表容器 | 详情容器 |
| --- | --- | --- |
| 数据中心 | 文件列表 | — |
| 审核广场：入库审核 | 申请列表 | 申请详情 |
| 审核广场：删除审核 | 申请列表 | 申请详情 |
| 审核广场：文件等级调整 | 筛选结果 | — |
| 审核记录：入库审核 | 记录列表 | 记录详情 |
| 审核记录：删除审核 | 记录列表 | 记录详情 |
| 审核记录：变更记录 | 文件等级变更卡片列表 | — |
| 人员管理 | 成员列表 | — |

首次读取及刷新均在内容区域水平、垂直居中展示转圈 loading。成功空列表（包括筛选后无匹配）淡入 `empty.webp` 和“空空如也”；没有选中详情时淡入 `sleep.webp`，不附加空状态文字。状态退出后再淡入内容，空图标不会与新内容重叠；减少动画偏好下直接切换。加载与空状态期间内容不可交互，但插槽内容保持挂载，避免刷新销毁表单草稿；接口失败显示错误和重试，保留上次结果，不伪装为空列表。

文件原件展示器保留现有居中转圈、文件类型分发和专属错误恢复；平台文件夹属于状态筛选区域，周期同步不清空已有实体；首次进入应用的分子背景及五色加载动画不受此规则影响。人员权限弹窗中的空平台权限是字段状态，不替代整条员工详情。详见[文件展示器](file-preview.md)、[平台模型](platforms.md)及[人员管理](personnel.md)。
