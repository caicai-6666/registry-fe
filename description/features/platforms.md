# 平台模型与查询接入

平台概览采用一个平台对应一个独立文件夹实体的设计，展示名称与存活状态。已接入注册中心人员鉴权的平台列表与同步时间接口，前端按后台计划更新，不再配置本地固定探测间隔。

## 平台实体展示

[`PlatformOverview.vue`](../../src/components/PlatformOverview.vue) 接收平台目录的只读响应式快照，按唯一代号排列 [`PlatformCard.vue`](../../src/components/PlatformCard.vue)。每个实体包含名称、状态与独立悬停效果，采用用户提供的 Uiverse.io / Cobp 文件夹模板，并转换为项目原生 CSS；不需要 Tailwind。

文件夹实体为 110px × 74px，每个平台占 136px，平台间距 6px，减少概览占用高度。文件夹在数据中心左侧筛选栏按宽度换行，较多时纵向滚动。区域高度最多为视口高度的 40% 且不超过 300px，较矮窗口可继续滚动整个左侧栏。名称最多显示两行，但单行名称不预留第二行空白，状态距名称底部为 4px。完整名称与描述可通过提示查看。文件夹开合只由选中状态控制，悬停或聚焦不会打开；点击或使用 Enter／Space 切换。减少动画偏好下直接显示选中姿态，不播放翻转过渡。

列表可视区域顶部 12px、底部 16px 使用纵向渐变蒙版，让边界处的文件夹、名称与状态柔和渐隐；蒙版不覆盖顶部控件，也不拦截点击或滚动。封面使用 [`platformAppearance.js`](../../src/config/platformAppearance.js) 中的八组配色，各组包含背板、封面底色和高光色。按平台唯一代号稳定分配，刷新、重排和开合不会换色，颜色不表示在线或选择状态。[查看羽化与多色封面效果](../assets/screenshots/platform-colors-feather.jpg)。

平台模型的在线状态显示绿色呼吸灯与“在线”，离线状态显示静态灰色圆点与“离线”。呼吸周期为 2.4 秒，亮度和光晕平滑变化；不移动圆点或文字。状态行使用固定高度，只有在线、离线或未知状态真正变化时才执行 240ms 淡入淡出；相同状态的新响应保留原节点和呼吸动画，不重播过渡。减少动画偏好下显示静态绿色圆点并关闭淡入淡出。

过期结果保留旧实体并显示“状态待更新”，不把不可确认的状态伪装为在线或离线。当前列表接口返回全部平台（包括 registry），文件夹展示排除 registry，并仅保留 `is_sub_management_platform=true` 的平台，符合标记的离线平台（`is_alive=false`）同样展示；前端不按存活状态过滤。某平台不再出现在成功响应中时淡出该实体，新平台淡入，已有平台调整位置时平滑移动；不将缺席推断为平台目录中仍存在但离线。

[查看在线与离线状态的隔离界面样例](../assets/screenshots/platform-status-preview.jpg)。样例展示接口支持的在线和离线两种状态。

平台区域不显示标题、区域编号、平台数量提示、刷新按钮或同步中的临时状态提示，保留辅助技术使用的区域名称。顶部左侧提供全选框，右侧显示距后端下次同步的倒计时，每秒按计划时间与当前时间的差值重新计算；显示为 `分:秒`，超过一小时显示 `时:分:秒`。到点后保持 `00:00`，不出现负数或切换成进度文案；无计划时显示 `--:--`，计划请求失败时显示对应异常。倒计时计时器只更新显示，不触发额外接口请求，计划清空或组件卸载时停止。

倒计时使用固定 160px × 24px 的专属区域，标签和数字分别布局。数字区宽度固定为 72px，使用等宽字体和右对齐，时间位数或数字变化不会移动标签，也不会推动平台实体；未获取计划时保留同样的空间并显示 `--:--`。计划异常信息单独显示，不替换倒计时区域。

[查看固定区域的隔离布局样例](../assets/screenshots/platform-countdown-fixed.jpg)。浏览器测量确认从 `01:00` 更新到 `00:42` 时，区域、标签、数字及平台文件夹的位置与尺寸完全一致。

成功响应为空时显示“暂无子平台”，仅表示没有符合条件的非自身子管理平台，不表示所有平台离线；加载和失败均有对应状态。筛选工具与正式文件列表见[目录与筛选](catalog.md)。

## 平台选择与筛选预布局

文件夹默认关闭，打开表示该平台已加入筛选选择，再次点击关闭并取消选择。平台选择与存活状态独立，离线平台仍可选择并参与全选；同一平台在线／离线切换不会移除实体、重置选择或开合。

“全选”采用用户提供的 Uiverse.io / byllzz 模板，保留不规则圆角、黑色边框、偏移阴影及勾选动画，选中颜色改为绿色。支持全选、取消全选与部分选中的横线状态；部分选中时点击全选会选择全部当前平台。原生 checkbox 保留键盘与辅助技术支持，无平台时禁用。

[`usePlatformSelection()`](../../src/composables/usePlatformSelection.js) 管理只读 `selectedCodes`，使用平台唯一代号存储筛选选择。状态由数据中心视图持有，`DataCenterPanel` 将 `selectedPlatformCodes` 传入概览，并转发单个平台和全选事件。结果列表复用同一选择数组，对来源平台代号进行本地筛选；空选择显示全部记录，不向后端追加未提供的筛选参数。

后台刷新保留仍存在的平台选择，移除已不在成功结果中的代号；新出现或移除后重新出现的平台默认关闭，不自动加入选择。三个导航页面之间切换保留选择，页面刷新或退出后重置。

[查看绿色全选与打开的文件夹](../assets/screenshots/platform-select-all.jpg)。截图为隔离交互样例。

所有启动方式均从后端读取真实平台列表及同步计划，临时十平台 mock 与开发开关已移除。多平台样式截图仅作为历史视觉预览保留，不表示当前后端返回的平台数量。

[查看后端计划调度联调截图](../assets/screenshots/platform-countdown-desktop.jpg)。账户与平台来自真实后端路由的隔离测试配置，不是实际生产数据。

## 公开平台模型

[`PlatformInfo`](../../src/models/platform.js) 保存 `code`、`name`、`description`、`isAlive`、`supportsA2a`、`isSubManagementPlatform`、`isManagementEntry` 和 `admins`；`fromApi()` 将后端蛇形字段映射为对应的驼峰属性。三个能力／类型标记均严格要求布尔值，缺失或类型错误时拒绝响应，不根据平台代号、存活情况或用户权限猜测。`supportsA2a` 仅保留信息，暂不参与页面筛选。`admins` 包含 userid、name 及头像文件名，人员管理按 userid 关联；只保存公开信息，不保留密钥、令牌或未知扩展字段。模型与列表不可修改，更新时整体替换。

`parsePlatformList()` 保留服务端顺序，接受空列表，拒绝重复代号、缺失字段、空白名称或描述、非法代号和错误类型。存活字段必须为布尔值，不接受字符串或数字；任一条目失败不返回部分列表。

`parsePlatformSyncTime()` 校验 `next_sync_at` 为带时区 ISO 8601 时间或 null，并统一为 UTC 字符串。字段缺失、旧 `updated_at` 字段、无时区时间及非法值均拒绝。

`isAlive` 仅表示中间件中存在有效登录会话，不表示平台业务健康。查询失败不能推断所有平台已退出登录。

## 接口与鉴权

具体契约以注册中心后端的[平台查看 API](../../../registry-be/description/api/platform.md)为准：

| 方法与路径 | 用途 | 成功响应 |
| --- | --- | --- |
| `GET /knowledge-accumulation/registry/api/platform/list` | 读取全部平台，包含 registry 和离线平台（`is_alive=false`） | 平台数组，字段为 `code`、`name`、`description`、`supports_a2a`、`is_sub_management_platform`、`is_management_entry`、`is_alive`、`admins` |
| `GET /knowledge-accumulation/registry/api/platform/sync-time` | 读取下一次计划同步或重试时间 | `{ "next_sync_at": "带时区时间或 null" }` |

两个接口均通过 [`registryApiRequest()`](../../src/services/registryApi.js) 使用 Bearer 用户 `access_token`，请求无 Body，禁止缓存。开发请求使用同源 `/dev/knowledge-accumulation/registry/api/`，网关与 Vite 均保留 `/dev`；构建部署使用同源 `/knowledge-accumulation/registry/api/`。不调用早先撤回的中间件列表地址，不在浏览器持有平台凭据。

列表接口返回 `503` 时说明目录不可用或过期，前端保留上次结果并标记未知；不能伪装成空列表。同步时间接口的 `200` 不代表平台列表可用。`next_sync_at` 是计划时间，不是完成时间或上次成功同步时间，null 可能表示正在同步，也可能表示未启用或没有后续计划。

## 按后端计划调度

[`createPlatformDirectory()`](../../src/services/platformDirectory.js) 提供只读 Vue 响应式快照：排除 registry 的 `platforms`、包含 registry 的 `allPlatforms`、从非自身目录筛出 `isSubManagementPlatform === true` 的 `subManagementPlatforms`、前端最后成功读取时间 `updatedAt`、后台计划 `nextSyncAt`、过期标记、刷新状态和列表／调度错误。`updatedAt` 仅是前端读取时间，不作为后端同步完成时间。

目录由 `WorkspaceLayout.vue` 统一持有，数据中心、审核广场、人员管理和审核记录共享；三个工作台任一可见或审核记录打开时查询列表与计划。有未来计划时，使用单次计时器在计划时间后 1 秒检查计划，给后台同步留出缓冲；收到新的未来计划后再读列表。正常同步期间保留现有实体和显示状态，不因为请求开始就标记过期或展示进度提示；列表接口明确失败或目录过期时才保留旧实体并标记未知。

计划为 null、已过期、格式错误或请求失败时，按 1、2、4、8、16、30 秒逐步退避重查同步时间，最多 30 秒；此时不周期探测平台列表。恢复有效未来计划后读取列表并重新按后端时间调度。该重试用于恢复调度，不是可配置的业务探测周期。

进行中的查询复用同一请求，重复启动不累积计时器或请求。长时间计划分段等待，避免计时器溢出。调度与倒计时使用浏览器系统时间，系统时钟应正确；后台标签页的浏览器调度可能延迟执行，恢复可见时重新读取计划和列表，并按实际时间差恢复倒计时。

离开三个工作台且审核记录未打开、标签页隐藏、退出或布局卸载时停止计时器并取消请求，保留内存中的旧实体；返回或恢复可见时重新获取。任一接口 `401` 停止调度，由鉴权处理展示失效提示及返回统一入口按钮。旧请求即使迟到，也不能覆盖停止或重启后的状态。

旧 `VITE_PLATFORM_POLL_INTERVAL_SECONDS`、Docker 构建参数和运行时 `setIntervalSeconds()` 已移除，无需为探测间隔重启前端或重建镜像。后台同步与重试周期由后端负责，前端仅读取其计划。

## 验证

此前自动测试覆盖公开模型、时间响应、Bearer 路径、按计划更新、空列表、后台正在同步、计划异常退避、过期结果、请求去重、取消与晚到响应、401、长计划及平台选择的保留与清理。`npm run build` 验证产物。浏览器检查悬停不打开、点击与键盘切换、全选／取消全选和部分选中状态。

上述测试及 FastAPI 隔离联调属于历史验证记录，原 `tests/backend_fixture.py` 已不在当前工作区，不能直接按旧夹具命令复现。当前可运行测试及验证限制见根目录 [README](../../README.md#构建预览与验证)。重新联调需准备独立数据与端口，不能占用真实后端或修改业务数据。

前端在平台列表解析后统一排除 `code === "registry"` 的注册中心自身平台，保留其他平台的原始顺序与在线／离线状态。数据中心的平台概览、全选及选择状态仅使用 `subManagementPlatforms`，包含符合标记的在线及离线平台；同步后标记变为 false 时清除对应选择。文件列表、审核记录等名称展示仍使用完整的非自身目录，不因筛选候选缩小而退回平台代号。空平台选择继续表示不限制来源，不会隐藏其他来源的文件。后续同步同样应用上述规则。
