# 审核广场三栏布局

审核广场采用横向三个区域，当前已接入正式入库及删除待审列表、详情、原件预览与审核提交；右上角已接入的审核历史弹窗与本页职责独立。

![当前审核广场桌面预览](../assets/screenshots/current-review-square-desktop.webp)

当前桌面截图使用隔离测试数据，不代表生产审核记录。

## 区域与交互

[`ReviewSquareView.vue`](../../src/views/ReviewSquareView.vue) 持有当前审核类型，默认选择“文件入库审核”。第一栏可切换“文件入库审核／文件删除审核”，第二栏为对应申请列表区域，第三栏为申请详情区域。入库和删除列表均来自正式待审接口，分别保存列表、选中项与提交状态，默认选中首条。

第一栏由 [`ReviewTypeNavigation.vue`](../../src/components/ReviewTypeNavigation.vue) 实现，视觉参考用户指定的 `flame-sport-pheno-manage-fe/src/components/layout/WorkspaceModuleLayout.vue`，采用浅色圆角侧栏、柔和径向渐变和单个选中滑块。入库使用紫色点缀，删除使用绿色点缀；图标使用用户提供的 `ingestion-review`、`deletion-review` PNG 转换而来的 WebP，保持 800×800 原始画布并采用无损压缩。界面按可见图形大小居中显示，通过混合模式让原图白底融入渐变，不裁剪图形；当前使用的图标资产位于 `src/assets/`，生产构建输出带内容哈希的独立 WebP 资源。

桌面导航项高度 74px、间距 9px，选中背景以 620ms 缓动在两项间移动，背景渐变以 5.8 秒周期流动。导航按钮保留独立图标与选中圆点，支持悬停、焦点和原生键盘激活。返回审核广场时播放导航入场，离开后暂停背景流动；列表与详情占位内容在类型切换时淡入淡出并轻微横移，离场内容设为 inert。

三个工作台路由保持挂载，因此离开再返回审核广场时保留审核类型。浏览器刷新恢复默认类型，不新增路由或持久化键。

## 尺寸与适配

桌面三栏分别为约 224–254px、250–320px、剩余宽度，间距 18px，页面四周留白 24px；中等窗口收紧宽度和间距。各区域保留后续独立滚动的布局边界。

760px 及以下改为顶部横向类型导航，下方依次排列申请列表和详情，选中滑块改为水平移动，避免挤压三栏内容。减少动画偏好下关闭入场、渐变流动、滑块和内容切换动画。

## 文件入库审核

[`useReviewApplications.js`](../../src/composables/useReviewApplications.js) 管理正式待审列表、现存通行证和提交状态，服务层位于 [`ingestionReviewApi.js`](../../src/services/ingestionReviewApi.js)。开发与生产均调用正式接口，页面不再包含示例申请、候选通行证或本地审核预览。

| 用途 | 接口 |
| --- | --- |
| 待审列表 | `GET /registry/api/ingestion-review/list` |
| 原件预览 | `GET /registry/api/resource/ingestion/{review_id}` |
| 提交决定 | `POST /registry/api/ingestion-review/{review_id}/decision` |
| 现存通行证提示 | `GET /registry/api/catalog/list`，合并文件的 `passport` 数组并去重 |

以上接口携带人员 Bearer 凭据，开发路径由统一 API 入口增加 `/dev` 映射。列表与决定响应使用精确 JSON 解析，SQLite 审核 ID 不经过有损数值转换。字段及错误契约以[后端入库审核 API](../../../registry-be/description/api/ingestion-review.md)为准。

进入入库审核、页面恢复可见或点击刷新时读取列表和现存通行证；离开或隐藏页面取消尚未完成的读取，忽略迟到响应。申请列表与审核记录弹窗共用 `RefreshButton.vue`，采用同一单箭头图标、白色圆形底及阴影，刷新动画以 0.8 秒转满一圈后停止，减少动画偏好下关闭旋转。刷新期间保留上次成功结果，失败显示错误及重试入口，不伪装为空列表。没有申请时在列表内容区居中淡入 `empty.webp` 及“空空如也”；该资源由用户提供的 `empty.png` 无损转换，源图保留。刷新期间保留空状态，收到新申请后先用 240ms 淡出图标和文字，再插入并淡入表项；退出最后一条时沿用列表滑出，空状态延后淡入，减少动画偏好下直接切换。[列表及详情空状态](../assets/screenshots/ingestion-empty-state.jpg)。保留仍存在的选中项，否则选择首条。

[`ReviewApplicationList.vue`](../../src/components/ReviewApplicationList.vue) 仅显示文件名称及其下方左对齐的来源平台名称，平台名称复用共享目录，查不到时回退代号。申请人、申请时间与其他申请信息在详情中展示。详情正文从文件摘要开始，后续依次展示申请信息、申请人备注及多个通行证建议。

审核员备注对通过与拒绝均为必填，纯空白无效，最多 10000 字。通过时将选中的现存通行证作为 `passport` 字符串数组提交，未选择则省略字段，由后端生成；拒绝始终提交 `passport: []`。审核员身份由后端会话确定，不从请求体传入。成功后移除对应申请并选中下一条：当前详情先在 260ms 内淡出，再更新内容并用 340ms 淡入；已处理列表项向左滑出并淡出，其他条目在 460ms 内平滑补位。列表退出项脱离布局且不可交互，不额外显示常驻成功提示。过渡期间锁定列表选择，详情组件保持挂载以保留其他申请草稿；最后一条退出后显示空列表，详情区居中淡入 `sleep.webp`；重新选中申请时先淡出图标，再淡入详情，列表空状态独立使用 `empty.webp` 和“空空如也”。减少动画偏好下直接更新。

通过和拒绝均采用按钮内的二次确认：首次点击仅进入橙色确认态，文字向上滚动，确认文字从下方进入；3 秒内再次点击才提交，超时则向下滚回原状态，不提供取消按钮。按钮尺寸固定，两种决定互斥；修改备注、通行证、切换申请或离开入库审核时清除确认状态。确认文字的 420ms 入场期间拦截连点，减少动画偏好下直接切换，仍保留二次确认与超时规则。[橙色确认按钮效果](../assets/screenshots/ingestion-decision-confirmation.jpg)。

二次确认后，当前操作按钮继续向上滚入“旋转图标＋提交中”，保持橙色和固定尺寸，并设置 `aria-busy`，不先回到初始文字；成功时维持加载态直至详情淡出，失败后结束加载并展示错误及重试入口。通过、拒绝和原请求重试均沿用当前操作的加载态，不额外添加提交提示。[按钮加载效果](../assets/screenshots/ingestion-decision-loading.jpg)。

提交期间禁用重复提交、列表选择和审核表单。超时、网络失败、503 或成功响应校验失败可能发生在决定已保存之后，因此保留原始决定、备注与通行证，锁定编辑并提供“重试原审核决定”。重试沿用原请求，不擅自改为另一种决定；明确的 4xx 业务错误展示后端信息并允许修正。切换类型不会取消正在提交的决定，提交状态保存在工作台组件中；刷新或退出后不持久化草稿及未确认请求，应以后台处理和重新拉取的待审列表为准。

桌面审核表单位于详情底部，详情正文独立滚动；窄屏表单跟随详情排列，整页可滚动到审核按钮。未提交的备注和选择按申请暂存，类型切换或刷新不保证保留；不将业务草稿写入持久存储。

## 通行证多选

[`PassportSelector.vue`](../../src/components/PassportSelector.vue) 位于审核备注之前。点击“＋”弹出搜索框，按前缀提示现存候选，选中后收起并将焦点返回新增按钮。候选去重、排除已选，最多显示 20 条；支持点击、上下方向键及回车，Escape 收起。仅允许选择正式目录中的现存值；未选时提示由后台自动生成新的通行证。目录读取失败单独提示并提供重新加载，不阻断待审列表展示。

已选项保持单行，选择区域高度固定为 44px，超出后左右滚动，新增按钮始终可见。新增后平滑滚动到末尾，也支持触控板、触摸及聚焦后的左右方向键浏览。新增项弹性位移淡入，移除项缩小淡出，其余项平滑补位；减少动画偏好下关闭过渡并立即滚动。共享值规则见[通行证数组契约](catalog.md#通行证数组契约)。

## 待入库文件预览

摘要右侧“文件预览”按钮以审核 ID 请求原件，不使用正式资源 ID。复用通用预览弹窗、加载状态、失败重试、摘要与页面内 Blob 缓存，关闭弹窗保留下载缓存，离开审核广场关闭弹窗。404、409、503 显示后端错误，401 走统一登录失效处理。

根据实际 `Content-Type` 分发 PDF、音频或视频；通用二进制才回退到响应文件名或申请名称。媒体使用浏览器原生播放控件，不自动播放，编码支持取决于浏览器。其他类型保留新窗口打开入口。详见[文件展示器](file-preview.md)。

## 文件删除审核

删除审核复用 [`ReviewApplicationDetail.vue`](../../src/components/ReviewApplicationDetail.vue)、申请列表、统一刷新按钮、`empty.webp`／`sleep.webp` 空状态、三秒超时的橙色二次确认、按钮加载与成功退场／补位动画。两种类型的列表和决定状态独立；请求失败或超时时保留原请求重试。类型切换不取消已发出的审核决定，不将入库决定发送至删除接口。

| 用途 | 接口 |
| --- | --- |
| 待删除申请 | `GET /registry/api/deletion-review/list` |
| 文件名称与摘要 | `GET /registry/api/catalog/list`，按资源 ID 精确关联 |
| 原件预览 | `GET /registry/api/resource/file/{resource_id}` |
| 提交删除决定 | `POST /registry/api/deletion-review/{review_id}/decision` |

删除申请本身没有名称与摘要，前端只从正式目录补充这些展示字段，不替换删除申请的来源平台、申请人、申请时间、删除原因或原通行证。目录缺失时以资源编号显示名称，摘要显示暂无；目录读取失败单独提示并支持重试，待删列表仍可展示。原件使用正式资源 ID，审核提交使用删除审核 ID，均保留 BIGINT 精度。

详情从文件摘要开始，展示来源平台、资源编号、删除申请人及时间、删除原因和原通行证数组。原通行证为只读，不显示推荐或选择组件。通过、拒绝均要求填写备注；请求体仅含 `{ approved, note }`，不发送新通行证或审核员身份。响应校验审核 ID、资源 ID、状态、approved 及完整发布回执；503 可能已经执行删除，必须以相同决定和备注重试。

既有测试及构建验证通过；隔离后端实际路由验证目录关联、正式原件 PDF 预览、原通行证多值、必填备注、两种决定、二次确认和 loading、503 原请求重试、类型切换状态隔离、成功后的补位及空状态。测试后端收到的删除请求只有 approved 和 note，无 passport；未操作真实业务审核记录。[删除审核详情](../assets/screenshots/deletion-review-detail.jpg)。
